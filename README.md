# Smile Clinic - أداة قياس الأشعة السنية (Android)

تطبيق أندرويد أصلي مبني بلغة **Kotlin** وواجهة **Jetpack Compose** لقياس أطوال القنوات الجذرية، العظم، والغرسات على صور البانوراما والأشعة الذروية (JPG, PNG, BMP, TIFF, DICOM).

## طريقة الفتح والبناء في Android Studio
1. فك الضغط عن مجلد `SmileClinicRadiograph`.
2. افتح **Android Studio** واختر **Open** ثم حدد مجلد المشروع.
3. انتظر حتى ينتهي Gradle من تحميل الاعتماديات تلقائياً.
4. اضغط **Run** لتشغيله على هاتفك أو محاكي أندرويد، أو اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)** لتوليد ملف التثبيت `.apk`.

## الميزات المضمنة
- **دعم DICOM مدمج:** قراءة ملفات `.dcm` واستخراج `PixelSpacing` تلقائياً مع تحسين التباين (0.5% - 99.5%).
- **معايرة مرجعية:** المعايرة باستخدام جسم معروف الطول داخل الصورة أو إدخال مقياس الحساس ومعامل التكبير يدوياً.
- **عدسة مكبرة (Loupe):** تظهر أعلى الإصبع عند سحب النقاط لضمان دقة التحديد على ذروة الجذر.
- **تصدير النتائج:** حفظ جدول القياسات بصيغة CSV (يدعم العربية في Excel) أو تصدير صورة PNG مُعلّمة بالخطوط والأرقام.
